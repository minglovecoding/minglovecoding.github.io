最基础的操作。

```
import os
import openpyxl

path = r"C:\Users\zmz\Desktop\爬虫"
os.chdir(path)  # 修改工作路径

workbook = openpyxl.load_workbook('121.xlsx')  # 返回一个workbook数据类型的值
sheet = workbook.active  # 获取活动表
# print(sheet.dimensions)     # 获取表格的尺寸大小

cell = sheet.cell(row=3, column=2)  # 获取第3行第4的数据

print(cell.value, cell.row, cell.column, cell.coordinate)

'''
结果：
41 3 2 B3
'''
```
